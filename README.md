# Oguz Kahraman — Professional Engineering Portfolio

## Upload instructions
1. Download and unzip this package.
2. In your GitHub `portfolio` repository, choose **Add file → Upload files**.
3. Drag all files and folders from inside this package into the upload area.
4. Commit the changes to the `main` branch.
5. Wait 1–3 minutes, then refresh:
   `https://oguz-kahraman.github.io/portfolio/`
